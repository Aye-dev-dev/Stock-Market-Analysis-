# Stock Market Analysis and Visualization Using Python

## Project Overview

This project explores historical stock market data using Python
to analyze price movements, financial returns, volatility,
and relationships between major publicly traded companies.

The analysis focuses on:

- IBM (International Business Machines)
- INTC (Intel Corporation)
- CSCO (Cisco Systems)
- GE (General Electric)
- Dow Jones Industrial Average

## Objectives

- Analyze historical closing stock prices.
- Compare the performance of selected companies.
- Calculate daily stock returns.
- Examine correlations between stock returns.
- Evaluate historical stock volatility.
- Develop interactive financial visualizations.

## Technologies Used

## Project Workflow

### 1. Data Preparation
Imported and cleaned historical stock price data.

### 2. Exploratory Data Analysis
Examined stock price distributions and descriptive statistics.

### 3. Financial Analysis
Calculated daily returns, total returns, and volatility.

### 4. Data Visualization
Created visualizations to examine stock price movements,
normalized performance, return correlations, and volatility.

### 5. Interactive Visualization
Developed interactive stock price charts using Plotly.

## Financial Metrics

Daily Return:

R(t) = ((P(t) / P(t-1)) - 1) × 100

Normalized Price:

Normalized Price = (P(t) / P(0)) × 100

Volatility:

Measured using the standard deviation of daily returns.
